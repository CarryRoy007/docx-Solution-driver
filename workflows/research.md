# 搜索调研子流程

> Phase 3 执行时的详细操作指南。

## 1. 识别内容缺口

对比大纲中每个章节与已有素材的覆盖情况:

### 缺口判断标准
- **无素材支撑**: 没有任何相关输入 → 必调研
- **部分支撑**: 有素材但信息不完整/过时 → 补充调研
- **有支撑但质量低**: 素材过于营销化/缺乏技术细节 → 调研替换

## 2. 生成搜索计划

```bash
python3 ${SKILL_DIR}/scripts/search_helper.py \
  --queries "查询词1" "查询词2" ... \
  --output <project_dir>/04_research/
```

## 3. 执行搜索

使用 `anysearch_search` 执行实际搜索:

```
对每个查询词, 执行:
  anysearch_search(query="<查询词>", max_results=10)
```

## 4. 质量过滤

搜索结果按质量分级:

**高优先级 (优先引用)**:
- 政府网站 (.gov.cn)
- 行业标准/白皮书
- 信通院、工信部等官方报告
- 学术论文

**中优先级 (可参考)**:
- CSDN/知乎/简书等技术博客
- InfoQ/开源中国等技术媒体
- 知名咨询公司报告

**低优先级 (避免引用)**:
- 纯营销文案
- 标题党/噱头内容
- 信息密度低的宣传页
- 已明显过时的内容

## 5. 深度阅读

对高优先级结果, 使用 `webfetch` 或 `anysearch_extract` 获取全文, 提取关键论据和数据。

## 6. 呈现调研结果

```
🔍 关于"政策背景"的调研 (共 N 条, 精选 3 条):

1. 《XX行业十四五规划》 — 来源: 国务院官网 — 质量: 高
   "明确提出到2025年XX领域要实现数字化覆盖率80%以上"
   → 建议用于 1.1 政策背景段落, 数据可直接引用

2. 《XX技术白皮书2024》 — 来源: 中国信通院 — 质量: 高
   ...

采纳哪些? (可多选)
```

## 7. 引用规范

引用外部资料时:
- 标注来源和年份
- 数据引用需要验证多个来源一致性
- 避免照搬大段原文, 用自己的语言概括
- 政策引用写全官方发文名称和文号
