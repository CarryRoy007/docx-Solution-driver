# 图表类型选择指南

> 根据内容需求选择合适的图表类型。

## 系统架构类

### 分层架构图
- **适用**: 展示系统分层结构 (接入层/服务层/数据层等)
- **SVG 模式**: 横向/纵向分层矩形, 层内放置子模块
- **颜色**: 不同层用不同色调的蓝色区分

### 组件关系图
- **适用**: 展示系统内模块间的调用/依赖关系
- **SVG 模式**: 方框 + 箭头
- **注意**: 箭头不要交叉太多, 复杂时可拆成多张子图

### 部署架构图
- **适用**: 展示服务器/网络设备物理部署
- **SVG 模式**: 服务器图标 + 防火墙 + 交换机 + 连接线

## 流程类

### 业务流程图
- **适用**: 展示业务流程步骤和分支
- **SVG 模式**: 泳道图 (横向分区, 纵向流程)
- **关键元素**: 起止节点(圆角矩形)、处理节点(矩形)、判断节点(菱形)

### 数据流图
- **适用**: 展示数据在各系统间的流转
- **SVG 模式**: 系统框 + 数据流箭头 + 数据标注

### 时序图
- **适用**: 展示多个参与者之间的消息交互时序
- **SVG 模式**: 生命线 + 箭头消息
- **注意**: 参与者不超过6个, 否则可读性差

## 计划类

### 甘特图
- **适用**: 展示项目时间计划和里程碑
- **SVG 模式**: 横向时间轴 + 任务条
- **关键**: 标注里程碑节点

### 路线图
- **适用**: 展示产品/项目分期规划
- **SVG 模式**: 时间轴 + 阶段标注

## 数据类

### 柱状图/条形图
- **适用**: 对比不同项目的数值
- **限制**: 类别不超过8个, 否则拥挤

### 饼图/环形图
- **适用**: 展示构成比例
- **限制**: 分类不超过6个, 太多小比例合并为 "其他"

## SVG 绘图原则

1. **所有文字元素必须指定中文字体栈**：
   ```
   font-family="PingFang SC, Heiti SC, Microsoft YaHei, Hiragino Sans GB, Arial Unicode MS, sans-serif"
   ```
   这确保 cairosvg 渲染 PNG 时中文不会变成方框。

2. 所有重要元素必须有 `id` 属性
3. 用 `<g id="...">` 组织逻辑分组
4. 文字使用 `<text>` 元素，字号≥11px
5. 避免使用 `<foreignObject>` (DOCX 不支持)
6. 颜色统一: 主色 #2563EB (蓝), 辅色 #10B981 (绿), 强调色 #F59E0B (黄)
7. viewBox 推荐: `0 0 960 640`

## Claude Zone 风格 (推荐默认风格)

> 此风格是 `deploy_gateway.svg` 的设计语言，灵感来自 Claude 官网视觉体系。
> 专业、现代、分区清晰，适合技术方案类文档中的架构图。

### 核心特征

| 元素 | 规范 |
|------|------|
| **分区 (Zone)** | 用虚线边框 `stroke-dasharray="6,3"` 的圆角矩形界定逻辑区域 |
| **分区背景** | 对应的渐变色，`opacity="0.04~0.08"`，极致淡雅 |
| **分区标题** | 左对齐 bold，颜色与分区主色一致，字号 13-14px |
| **内容卡片** | `fill="white"` + 1.5px 彩色边框 + `rx="6"` 圆角 |
| **阴影** | `feDropShadow` + `flood-opacity="0.06~0.12"`，轻量精致 |
| **箭头** | 彩色 marker，与来源分区色一致 |
| **图例** | 底部色块 + 文字，一行排列 |
| **画布** | `#f8fafc` 浅灰白背景 |
| **标题** | 居中 bold，字号 20px，`#1e293b` |

### 分区颜色方案

| 用途 | 渐变起→止 | 描述 |
|------|----------|------|
| 蓝 | `#2563eb→#3b82f6` | 接入层、API网关、核心架构 |
| 橙 | `#d97706→#f59e0b` | 数据处理、中间件、LLM |
| 绿 | `#059669→#10b981` | 数据存储、目标端、输出 |
| 紫 | `#6366f1→#a5b4fc` | 基础设施、管理、审计 |
| 红 | `#dc2626→#f87171` | 外部网络、危险区域、告警 |
| 青 | `#0891b2→#22d3ee` | 消息队列、流处理 |

### 模板库

| 模板文件 | 适用场景 |
|---------|---------|
| `zone_arch_system.svg` | 通用分层系统架构 (接入→服务→数据→基础设施) |
| `zone_data_flow.svg` | 数据流转架构 (数据源→处理→存储→消费) |
| `zone_microservice.svg` | 微服务架构 (网关→服务集群→注册中心→可观测) |
| `zone_network_topo.svg` | 网络拓扑 (外部→DMZ→应用→数据→管理网) |
| `deploy_gateway.svg` | API网关集成部署 (客户端→网关→服务→监控) |

### 使用优先级

除非用户明确选择其他风格，否则 **默认使用 Claude Zone 风格** 生成所有架构类图表。流程图仍使用标准的起止圆角矩形+菱形判断+箭头模式。
